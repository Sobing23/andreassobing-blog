Schriftarten für dein E-Mail-Marketing: Viele E-Mails Clients wie Outlook unterstützen nur einige Schriftarten für die Darstellung in E-Mails. Diese nennen sich Web Safe Fonts.

**Zu diesen zählen folgende Schriftarten:** 

- Arial
- Helvetica
- Verdana
- Georgia
- Times New Roman

<div class="video" data-provider="youtube" data-id="qLJpqR6wSQg"></div>

Solltest du weiterhin deine eigene Hausschrift verwenden wollen, kannst du die passenden Web Safe Fonts als Fallback-Variante eingesetzt werden. So kann sichergestellt werden, dass auch bei Ausfall der genutzten Webfont eine lesbare E-Mail Version zur Verfügung steht. Ich würde allerdings gerade zum Start einfach eine der gängigen Web Safe Fonts nutzen. Später kannst du diese immer noch als Fallback einrichten und deine eigene Schrift einsetzen.
